# 🌌 Personal Portfolio

A personal portfolio website built with Django, showcasing my skills, projects, and journey in Artificial Intelligence, Data Science, Python, and Web Development.

## ✨ Features

- Modern space-themed UI
- Animated hero section
- Typing text animation
- Interactive navigation
- Responsive design
- Built with Django

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- Typed.js

## 🚀 Getting Started

```bash
git clone https://github.com/Renjinirj/Portfolio.git
cd Portfolio
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```
